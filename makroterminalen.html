Makroterminalen

An analysis platform for macroeconomic, financial and political data, built in Python and Streamlit since 2026.

Why it exists

Economic debate is full of claims that are easy to state and slow to check. Testing one usually means downloading spreadsheets from several statistical agencies, aligning their definitions and frequencies, and only then getting to the actual question. I built Makroterminalen so that the same check takes a few minutes: the data is already in one place, in one format, and the tools for analysing it sit next to it.

What it covers

The platform brings together macroeconomic data on growth, prices, interest rates, labour markets, trade and public finances, alongside market data and portfolio analysis. A world map and a geopolitics section follow conflicts and geopolitical risk, and separate pages cover politics, democracy and political economy. At its centre is an econometrics lab with OLS, GLM, ARIMA, VAR and panel data models, each reported with diagnostics and robustness checks. Around it are simulations, from Monte Carlo and bootstrap to game theory and simple macro models, a machine learning section and a report tool that turns an analysis into a document.

How it is built

Everything rests on a common variable register. Sixteen adapters fetch data from 29 distinct sources and describe each series in the same way, so that a variable looks the same regardless of where it comes from. The register currently holds 108,146 variables. The application has 24 pages, runs in Swedish and English through a translation layer, and comes in five colour themes. Each model prints its own formula, generated from the code rather than copied from a textbook, and a static check makes sure it stays that way. A test suite runs every page in both languages and all themes. I developed the platform with AI coding tools, which let me spend my time on the economics and on checking the results.

Sources

The data comes from open sources: the ECB, Eurostat, FRED, the IMF, the OECD, the European Commission’s DG ECFIN, Our World in Data, Statistics Sweden and other PxWeb registers, UNHCR, Reporters Without Borders, the Geopolitical Risk Index, HDX HAPI, the Uppsala Conflict Data Program, V-Dem and the World Bank.
